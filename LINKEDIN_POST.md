🚀 Excited to introduce AI Career Copilot — an end-to-end, AI-powered career development platform!

Job hunting today is fragmented. Candidates use one tool to parse their resume, another for ATS scoring, another to practice mock interviews, and separate job boards to search for open roles.

I built AI Career Copilot to streamline the entire candidate journey into one unified, intelligent ecosystem.

💡 Key Innovations & Core Features:
📄 Multi-Parser Resume Cascade: Preserves multi-column layout order using PyMuPDF and pdfplumber, backed by a Candidate Confirmation Gate to eliminate extraction errors.
📊 Deterministic ATS Scoring Engine: A mathematical, weighted matching algorithm that provides line-by-line supporting evidence from your resume (no random LLM scoring!).
🤖 LangGraph Agentic Workflows: Multi-agent self-correction loop (GAP_ANALYST ➔ RESUME_IMPROVER ➔ EVIDENCE_VALIDATOR) that validates resume bullet enhancements against confirmed data to prevent AI hallucinations.
🎙️ Interactive AI Voice Mock Interviewer: Evaluates responses using a STAR (Situation, Task, Action, Result) 100-point rubric with real-time Speech-to-Text, Fish Audio TTS, and webcam gaze tracking.
📺 Anti-Hallucinated Skill-Gap Learning Paths: Integrates directly with YouTube Data API to fetch verified educational video metadata for identified skill gaps.
🌐 3D WebGL Job Globe: Interactive job discovery globe built with Three.js & Cobe powered by real-time Adzuna API job listings.

💻 Tech Stack:
• Frontend: React, TypeScript, TailwindCSS, Three.js / Cobe, Vercel
• Backend: Python, FastAPI (Async), Pydantic, Render
• AI / Agents: LangChain, LangGraph, Groq LLaMA 3.3 70B
• Databases: Supabase (PostgreSQL), Firebase Firestore
